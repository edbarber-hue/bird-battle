# Who Would Win? Bird Battle

Play it online at **https://edbarber-hue.github.io/bird-battle/**, or open `index.html` in Chrome, Safari, or Edge. Share that browser window in Zoom.

## Run the game

1. Have people vote aloud or in Zoom chat.
2. Click the bird that won. That bird stays to face the next challenger.
3. Sparrow is always the final challenger.
4. Click **Start presentation** after the last vote.

Toucan and Macaw open each game. The other challengers are shuffled. **Undo pick** reverses the latest result, and **New game** starts again.

## Edit the presentation

Open **Slides** at any time. Edit the heading and body, add or duplicate slides, and optionally add artwork. Click **Present** to show the slides full screen. Use the arrow keys or buttons to move through them, and **Escape** to leave presentation mode.

Slides and the current game save automatically in that browser. **Download slide backup** saves an editable JSON copy that you can import later. If you plan to use a different computer, download a backup and copy this entire folder to it.

The game uses local bird images, so the matchups work without internet. The optional image URL field in slides requires a connection; uploaded slide images are saved in the browser. Image source and license details are available through **Image credits**.

The Tweety Bird slot uses an original yellow cartoon bird illustration as a stand-in.
